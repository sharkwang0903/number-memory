# 數字瞬間記憶

一款輕量、適合快速遊玩的數字瞬間記憶小遊戲。

畫面會短暫顯示一串數字，數字消失後，玩家必須依照原順序輸入答案。每成功通過一題，下一題會增加一位數字。遊戲從 4 位數字開始，持續挑戰自己能記住的最大數字長度。

規則直觀、遊玩時間彈性，也能透過挑戰個人最佳紀錄增加重玩性。本遊戲僅供娛樂使用，不是醫療或心理診斷工具。

## 遊戲規則

- 遊戲從 4 位數字開始。
- 玩家按下「準備完成」後，數字才會出現。
- 按下按鈕後會先短暫留白約 0.5 秒，再顯示數字。
- 數字顯示一段時間後會自動消失。
- 玩家可以使用畫面上的虛擬數字鍵盤輸入答案。
- 桌機玩家也可以使用實體鍵盤。
- `0–9`：輸入數字
- `Backspace`：刪除最後一位
- `Enter`：提交答案
- 答對後，進入更高一位數字的挑戰。
- 同一位數字第一次答錯時，可以再挑戰一次。
- 第二次挑戰會重新產生一組新的數字。
- 同一位數字連續失敗兩次，遊戲結束。

每題的數字會重新隨機產生，第一位不會是 `0`，其餘位置可以出現 `0`，數字也可以重複。

## 數字顯示時間

目前使用以下公式決定數字顯示時間：

```text
T(n) = min(2.5, max(1.0, 0.25 × n))
```

其中：

- `n` 為目前數字位數
- `T(n)` 單位為秒

範例：

| 數字長度 | 顯示時間 |
| --- | ---: |
| 4 位數字 | 1.0 秒 |
| 5 位數字 | 1.25 秒 |
| 6 位數字 | 1.5 秒 |
| 8 位數字 | 2.0 秒 |
| 10 位數字以上 | 2.5 秒 |

位數增加時，顯示時間會適度增加，但最多維持在 2.5 秒。

## 稱號系統

結果頁會依照本次最高成功通過的數字位數顯示稱號：

| 最高成功長度 | 稱號 | 評語 |
| --- | --- | --- |
| 4–5 位數字 | 記憶見習生 | 「旅程才正要開始。」 |
| 6–8 位數字 | 記憶覺醒者 | 「你的腦袋開始進入狀態了。」 |
| 9–10 位數字 | 記憶支配者 | 「數字正在你的腦中排隊。」 |
| 11–13 位數字 | 記憶超越者 | 「這已經不是普通人的記憶力了。」 |
| 14 位數字以上 | 過目不忘之人 | 「你真的有忘記過東西嗎？」 |

14 位數字不是遊戲上限，玩家仍可以繼續挑戰 15、16、17 位數字及更高位數。

## 個人最佳紀錄

遊戲使用瀏覽器的 `localStorage` 保存個人最佳紀錄。

重新整理頁面後，紀錄仍會保留。若本次遊戲刷新個人最佳成績，結果頁會顯示「新的個人紀錄！」提示。

## 專案檔案結構

```text
number memory/
├── index.html
├── style.css
├── game.js
├── ui.js
├── storage.js
└── README.md
```

### `index.html`

負責網頁基本結構、遊戲各個畫面容器、按鈕與虛擬數字鍵盤。

### `style.css`

負責整體視覺風格、響應式版面、虛擬鍵盤、按鈕樣式與淡入淡出動畫。

### `game.js`

負責遊戲核心邏輯，包括遊戲狀態、隨機數字生成、數字顯示時間、挑戰位數、答案判斷、失敗與成功流程、最高成功長度及稱號判定。

### `ui.js`

負責畫面切換、按鈕事件、虛擬鍵盤操作，以及 `0–9`、`Backspace`、`Enter` 等實體鍵盤輸入。

### `storage.js`

負責使用 `localStorage` 讀取、儲存與更新個人最佳紀錄。

## 如何執行

這是一個純前端專案，不需要安裝任何套件。

直接用瀏覽器開啟 `index.html` 即可遊玩。

也可以將整個資料夾部署到 GitHub Pages 或其他一般靜態網站服務。

## 使用技術

- HTML
- CSS
- JavaScript
- `localStorage`

## 設計風格

介面採用典雅、清爽的文青風格，使用以下視覺方向：

- 淺藍
- 淺黃色
- 米白與奶油白
- 低彩度配色
- 簡潔留白
- 柔和圓角與輕微陰影
- 克制的淡入淡出效果

整體避免過度動畫與強烈特效，讓玩家能專注於數字記憶挑戰。

## 後續可調整項目

以下內容都可以直接在現有程式中調整：

- 起始位數：`game.js` 的 `STARTING_DIGITS`
- 數字顯示時間與留白時間：`game.js` 的 `calculateDisplayTime()` 與 `BLANK_DELAY_MS`
- 稱號門檻與稱號文字：`game.js` 的 `getTitle()`
- 介面配色、尺寸與 RWD：`style.css`
- 遊戲難度：可透過調整起始位數與數字顯示時間公式控制
